# The shared fixture corpus for `FORMAT-differential`

**These bytes are read by BOTH decoders — the C++ classifier in
`engine-cpp/rig/differential_artifact.cc` and the Go reader in
`engine/differential/artifact.go` — and they are produced by NEITHER.**

They were built field by field from `docs/FORMAT-differential.md` by a generator
that implements crc32c itself and links no part of this project.

## Why that matters

The two decoders are deliberately independent implementations of one format.
A shared *encoder* would make them agree by construction, and the single bug a
frozen format exists to catch is a disagreement about what the bytes mean.

> **THE FIXTURES ARE THE SHARED ARTIFACT RATHER THAN THE CODE.** What is kept in
> step between the two languages is this directory, not two code paths.

A fixture generated by either encoder would test that that decoder agrees with
that encoder — the question the pair exists to *not* assume.

## The rule for adding one

**Hand-build it from the document.** If a new refusal is added to the format, its
fixture is written from the specification's text, and **both** decoders must be
shown to refuse it. A fixture that only one decoder has ever seen is a fixture
that proves nothing about the pair.

## What each file is

`legal-*` must be **accepted** by both. `refuse-*` must be **refused** by both,
and the two need not agree on which refusal fires when a file breaks more than
one rule — only that neither accepts it.
