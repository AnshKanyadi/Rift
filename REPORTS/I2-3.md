## 3. OPEN-I2-2 — the case, not the fix

`make chaos-smoke` is red on a **third** instance of GF-57's second signature.

```
panic: store: node 1 has made durable something its own record disagrees with:
recorded 2 durable entries above the snapshot, engine returned 3
```

This is the **continuous** cross-check in `onDurable`, not the recovery one BUG-059 fixed.

### The mechanism

```
1. driver applies writes at seqs 1..3, schedules durability for seq 1
2. the event fires -> realEngine.AdvanceDurable(1) -> DB.Sync()
3. Sync() has no per-sequence form: it makes 1, 2 AND 3 durable
4. the driver folds only w.seq <= 1 -> durLog holds 2 entries
5. the guard `visibleSeq() == DurableSeq()` passes, because the whole tail synced
6. readDurable() returns 3. The comparison fails.
```

`engine/model.AdvanceDurable(seq)` advances **exactly to seq**. `realEngine.AdvanceDurable`
**ignores it** — DESIGN-A0 §7's I1 idealization, recorded in advance and cited at the line.

### Why I am not touching it

The check's own comment states its premise: *"two independent derivations of one fact."* On a
whole-tail-sync engine **that premise is false.** The engine holds *more* than the driver
acknowledged, which is the safe direction — the invariant that matters is *never less*.

**Three dispositions, and I recommend the middle one:**

- **(a) Relax to `engine ⊇ recorded`.** A weakening. It stops catching a *different* entry at a
  recorded index, which is the failure the check exists for. **Not proposed.**
- **(b) Fix the GUARD, not the assertion.** `visibleSeq() == DurableSeq()` was written for an
  engine where equality implies the driver has been told everything. Replace with: compare only
  when the driver's pending set is empty **and** its last acknowledged sequence equals
  `DurableSeq()`. **No assertion changes** — this corrects a precondition that was accidentally
  engine-specific.
- **(c) Declare it not evaluable on this engine, skip, and COUNT the skips** — the answer given
  to `durRecorded` two layers up.

**Recommendation: (b), with (c)'s counter attached.** Count how many completions the corrected
guard declines to compare, so reduced frequency on the C++ engine is a number rather than a
silence. If (b) admits no comparisons at all there, it has become (c) and the counter says so.

### Why this blocks items 3 and 4

`scripts/mutants.sh` **refuses to attribute kills without a green baseline** — by design, and
correctly. A calibration fixture for `chaos/` (item 3) exists to be the covering target for
chaos-level mutants (item 4), and those mutants' covering tests are chaos tests, which are red.
**Not an excuse — a mechanical dependency in the lane's own contract.**

### GF-64, stated as a boundary

Removing `Recover()` from `restart()` leaves the machine `down` forever. **No safety oracle sees
it at any seed count**, because a crashed node that never returns is *legal*.

| | |
|---|---|
| **safety oracles cover** | anything that makes a **wrong** thing happen |
| **nothing covers** | anything that makes the **right** thing stop happening |

What would catch it is **a liveness assertion with a stated floor**, which this project has
deliberately never built: progress is *measured* (leader-ticks, completions, non-vacuity
counters) and measurement is not a gate. The floor is the hard part — too tight fails on a slow
machine, too loose fails nothing — and it would have to be derived from `Election` and
`Heartbeat` the way `R ≤ 2.5E` is, then measured against real schedules before it could gate.
**Not closed casually, and not proposed here.** The `LedTicks == 0` arm is the tree's only
liveness assertion, it is binary, and it would not have caught this either: a cluster with two
live nodes still elects a leader.

### GF-60 row 1, elevated: three mechanisms, one claim, three silences

| mechanism | why it did not exercise HLC uncertainty |
|---|---|
| A6's seeded sweep | ran with **skew off** |
| the determinism pass over `hlc` | **`hlc` was never analysed** (BUG-048) |

> Each was defensible in isolation: a sweep shape, an analyser default, a clock that reads the

> **A claim covered by three mechanisms is not three times as safe if nothing checks that any of
